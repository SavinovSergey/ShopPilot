# Recommender evaluation: popularity baselines

## Условия эксперимента

- Snapshot данных: `amazon-all-beauty-2023-v1`.
- Версия сигнала: `rating_implicit_uniform_v1`; протокол оценки: `global_calendar_v1`.
- Граница обучения (`cutoff`): `2021-01-01`; сравнение временных меток выполняется в UTC.
- Длина списка и порог метрик: `K=20`.
- Сравниваемые модели: `global_popularity` и `category_popularity`.
- Для ранжирования используются только положительные пары из `train`: уникальные пары пользователь–товар (`binary_unique_pair_v1`) и число положительных пар на товар (`positive_pair_count_v1`). Цели оценки берутся из `validation` и не участвуют в построении популярности.
- Пространство кандидатов ограничено товарами, известными по положительным `train`-парам (`positive_train_items_v1`). Уже встреченные пользователю в `train` товары исключаются из рекомендаций.
- Категориальная модель использует категории из текущего каталога. Эти метаданные не гарантированно соответствуют состоянию на дату `cutoff`, поэтому её результаты имеют ретроспективное ограничение.

Идентификатор конфигурации (`config_hash`): `67ee71023d952a96cb13dbdfab0fa4e1da1e54931b28160eff8f6a189d98abdc`. Машинные отчёты сохранены в `data/lake/recommender_evaluations/amazon-all-beauty-2023-v1/<config_hash>/k=20/`.

## Результаты

Оценка выполнена для tenant `beauty-demo`: 76 308 пользователей имеют положительные цели в `validation`, 43 568 из них имеют хотя бы одну достижимую цель и входят в знаменатель метрик качества. У остальных 32 740 пользователей достижимых целей нет; они сохранены в отчётах, но не влияют на средние Recall, HitRate, NDCG и MRR. Из 81 229 целевых товаров 44 557 входят в доступное пространство кандидатов, 14 уже встречались пользователю в `train`, а 36 658 неизвестны по положительным `train`-парам.

Для обеих моделей получены одинаковые средние по оцениваемым пользователям: Recall@20 — `0.035657`, HitRate@20 — `0.035944`, NDCG@20 — `0.014645`, MRR@20 — `0.008861`. Recall@20 остаётся основной защитной метрикой при сравнении следующих моделей.

Каталожное покрытие отличается: глобальная модель показала 21 уникальный товар из 67 374 кандидатов (`0.000312`), категориальная — 42 (`0.000623`). Средняя novelty составила соответственно `9.0720` и `9.0728` бит самоинформации. Более высокое покрытие не сопровождалось улучшением метрик попадания и ранжирования.

## Срезы пользователей

- `platform_cold`: 71 356 целевых, 40 949 оцениваемых пользователей; Recall@20 — `0.036143` у обеих моделей.
- `als_cold_nonpositive_only`: 872 целевых, 463 оцениваемых; Recall@20 — `0.047516` у обеих моделей.
- `short_positive_history`: 3 048 целевых, 1 640 оцениваемых; Recall@20 — `0.028963` у обеих моделей.
- `warm_positive_2_4`: 788 целевых, 367 оцениваемых; Recall@20 — `0.010899` у обеих моделей.
- `warm_positive_5_plus`: 244 целевых, 149 оцениваемых; Recall@20 — `0` у обеих моделей.

Списки рекомендаций различаются у 20 из 76 308 пользователей, но ни у одного пользователя из двух `warm_positive_*` срезов. У двух пользователей с `short_positive_history` изменился Recall: один потерял попадание, другой приобрёл; изменения взаимно компенсировались в среднем.

## Вывод и ограничения

В этом эксперименте категориальная модель не улучшила ни общие метрики качества, ни качество на тёплых пользователях. Большинство целевых пользователей относятся к `platform_cold`, поэтому получают глобальный fallback. Кроме того, текущий каталог содержит лишь две широкие категории — `All Beauty` и `Premium Beauty`; это ограничивает различие между категориальным и глобальным ранжированием.

Категории взяты из текущего каталога, а не из состояния на дату обучения: результат категориальной модели ретроспективен. Пространство кандидатов ограничено положительными `train`-товарами; неизвестные товары из `validation` не считаются промахами ранжирования. Доверительные интервалы для различий между моделями не рассчитывались, поэтому небольшие изменения покрытия и novelty не следует трактовать как доказанное улучшение.
